# Contributing

Thanks for improving Expense Tracker Local.

1. Use Python 3.10+ and create a virtual environment.
2. Install the project editable and install pytest: `python -m pip install -e . pytest`.
3. Add tests for behavior changes and run `pytest` before submitting changes.
4. Keep the core dependency-free unless a dependency provides clear, reviewed value.
5. Never commit real financial records, databases, credentials, or generated exports.
6. Keep CLI behavior backward-compatible where practical and update both English and Arabic README sections for user-facing changes.

Small, focused changes with clear commit messages are preferred.
