# Security

Expense Tracker Local operates offline and stores records locally.

The SQLite database and CSV/JSON exports are plaintext and may contain sensitive financial information. Protect them with operating-system file permissions, encrypted storage where appropriate, and suitable backups. Do not place passwords or access credentials in expense notes.

For security concerns, use an appropriate private GitHub contact channel for the repository owner when available. Avoid publishing sensitive vulnerability details before they can be addressed.
